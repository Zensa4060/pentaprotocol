# All versions are pinned with the `~=` ("compatible-release") operator:
# `~=A.B.C` allows patch-level updates (security fixes) but forbids
# minor or major bumps that could silently break the API. This is the
# sweet spot between a plain `==` lock (which rots fast on CVEs) and
# unpinned requirements (which caused the last "works on my machine"
# Railway incident).
#
# To tighten further for a full lockfile, run:
#   pip install pip-tools && pip-compile requirements.txt -o requirements.lock
# and commit requirements.lock. Railway can install from either file.
